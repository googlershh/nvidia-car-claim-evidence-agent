# 사건노트 DOCX 편집기

SuperDoc을 iframe으로 분리하고, `docx`로 사건의 협의 초안과 내부 보고서를 실제 DOCX로 생성합니다. A4 용지, 제목·본문 서식, 머리말과 페이지 번호를 포함합니다.

실행과 배포 방법은 [데모 안내](../README.md)를 참고합니다. 빌드는 `demo/dist/docx-editor/`에 생성되며 git에는 소스와 잠금 파일만 포함합니다.

## 편집본 보관

자료·질의 전환 중에는 iframe을 유지합니다. 문서 전환 전 편집본을 Blob으로 받아 협의 요청서와 내부 보고서별 작업 사본을 보관합니다. DOCX 열기는 현재 작업 사본을 바꾸고, 다운로드는 실제 DOCX 파일을 생성합니다.

새로고침하면 초기화되므로 보관할 편집본은 다운로드해야 합니다. 서버 저장·승인·외부 발송은 연결하지 않았습니다. 편집기는 동일 출처 자산과 브라우저 Worker에서 실행하며, 텔레메트리는 꺼져 있습니다.

빌드 스크립트가 의존성 라이선스와 고지, 통합 소스를 함께 패키징합니다. SuperDoc은 AGPL-3.0, docx는 MIT이며, DOCX Engine은 별도 라이선스로 SuperDoc 기반 평가 데모의 의존성으로 사용합니다.
