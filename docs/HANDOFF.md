# HANDOFF: 자동차보험 대물 손해사정 에이전트

claude.ai 대화 세션(2026-09-27)의 내용을 Claude Code로 넘기기 위해 압축한 문서.
사실 수치는 대화 중 웹 조사로 확인한 것이며 출처를 괄호로 적었다. 발표 자료에 쓸 때는 원문을 다시 확인할 것.

## 1. 해커톤 개요

- 행사: NVIDIA Agentic AI Hackathon. "질문에 답하는 챗봇이 아니라, 목표를 받으면 스스로 계획하고 도구를 호출해 문제를 해결하는 에이전트".
- 트랙: **Creative Use-case** (가장 독창적인 AI 에이전트 & 서비스 구현)
  - 목표: 스스로 판단·실행하는 에이전트로 진짜 문제를 푼다. 데모가 아닌 재현 가능한 코드와 작동하는 서비스.
  - 활용 도구: Nemotron, NIM, NVIDIA Agent Toolkit, NeMo Agent Skills, Skill Spector, OpenShell(NemoClaw)
  - 방향: GPU 활용이 주가 아닌, **다양한 모델 서빙 기반 에이전트 구현**이 주요.
  - 전제 조건: **NeMo Framework 또는 NeMo Microservices 활용. 재현 가능한 코드. 작동하는 데모.**
- 제공 인프라: DGX Spark, L40S 등.

## 2. 문제 선정 경위 (요약)

사용자가 준 기준:
- 핵심 5개: ① 보안·프라이버시 필수 도메인 ② 에이전트여야만 풀리는 다단계 업무(RAG 챗봇 X) ③ 해커톤 내 공개·합성 데이터로 재현 가능 ④ 효과를 숫자로 보여줄 수 있음 ⑤ 범위가 좁음
- GPU 스토리 3개: 추론량·상시가동, 멀티모달, 현장 복제성
- 추가 관점: 페인포인트 명확성, 실제 산업 현장 문제, 고객의 수익모델(손익)과 직결

과정: 사용자 엑셀(`FDE_글로벌_사례조사.xlsx`, FDE 사례 940건)에서 보안 필수 도메인 사례를 묶어 후보 30개 → 가중 루브릭(100점)으로 평가.

| 후보 | 전체(8기준) | 핵심 5기준 | 비즈니스 관점 |
|---|---|---|---|
| 실손보험 청구 심사 | 1위 (90) | 공동 2위 | 1위 (95) |

**최종 선택: 자동차보험 손해사정.** 이유: 멀티모달 점수 만점(블랙박스 영상+사진+견적서), 정답 라벨(과실비율)이 있는 공개 데이터 존재, 보험사 손해율에 직결, 데모 시각적 임팩트 큼.
대안(데이터 승인이 막힐 때): HS 품목분류(공개 데이터 중심, 2027~2028 제도 변화로 시의성 강함).

## 3. 문제 정의와 범위

**한 줄 정의:** 손해보험사 대물보상팀이 차대차 사고 1건을 받았을 때, 과실비율 초안과 수리비 인정액을 근거와 함께 만들고 이상 건을 골라내는 에이전트.

- 포함: 차대차 대물(차량 수리비) 1차 사정. 사고 장소는 **직선 도로, 신호 있는 사거리, T자형 교차로** (교통사고 영상 데이터의 약 60%).
- 제외(확장 로드맵 슬라이드로만): 대인·부상·경상환자 과잉진료, 전손, 보행자·이륜차 사고.
- 포지셔닝: "AI가 과실을 결정한다"가 아니라 **"근거 도표·판단 근거와 함께 초안을 내고 사람이 승인한다"**. 보험금 삭감 도구가 아니라 "정상 건은 빠르게, 이상 건만 선별".

### 발표용 페인포인트 수치
- 2025년 보험사기 적발액 1조1,571억 원 중 자동차보험 5,724억 원(49.5%)으로 최대. 병원의 자동차보험 악용 과장 청구 273억 원, 전년 대비 582.5% 증가. (금융감독원 2025년 보험사기 적발 현황 보도)
- 2025년 자동차보험 손익 7,080억 원 적자, 손해율 87.5%. (금감원 발표 보도)
- AI 과실 판정 도입 시 수리비 청구 기간 4일 → 1일 단축 기대. (AI Hub 교통사고 영상 데이터 소개 페이지의 서비스 활용 시나리오)
- 과실비율 상황 분류 참고 기준선: VTN 모델 F1 0.7591 (AI Hub 교통사고 영상 데이터). 과제가 같지 않으므로 "참고 기준선"으로만 제시.

## 4. 에이전트 워크플로

```
사고 접수 묶음(영상·사진·견적서·진술)
  └─ 플래너(Nemotron): 조사 계획 수립
       ├─ A. 과실 판단: 영상 분석 → 진술 대조 → 과실 인정기준 도표 검색 → 수정요소 증거 재탐색(루프)
       ├─ B. 손해액 검증: 파손 사진 판정(부위·손상종류·심각도) ↔ 견적서 파싱 → 항목 대조 → 단가 조회
       └─ C. 이상 징후: 사고이력 조회, 영상-사진 모순(예: 후방 추돌인데 전면 파손 청구), 충돌유형×충돌부위 참조표
  └─ 교차 검증·라우팅(근거 부족 시 재조사 ↻)
       ├─ 정상 → 손해사정서 초안
       ├─ 조정 필요 → 정비공장 조정 요청서
       └─ 의심 → SIU 이관 메모
  └─ 보상 담당자 승인 (HITL)
```

손해액 검증에서 잡을 4가지: 사진에 없는 부위 청구 / 경미 손상(심각도 1~2)인데 교환 청구 / 부품가가 제작사 공시가 초과 / 공임 과다.

도구(초안):
- `analyze_video(clip)` → 장소유형, 신호, 각 차량 진행, 충돌 시점 JSON
- `detect_objects(frame)` → AI Hub 제공 DetectoRS 결과(신호등 색 등 9종). 멀티모달 모델의 신호 오인식 보완용 하이브리드
- `search_fault_table(query)` → 손해보험협회 과실비율 인정기준 RAG
- `assess_damage(images)` → 부위·손상종류·심각도
- `parse_estimate(doc)` → 견적 항목
- `lookup_part_price(model, part)` → 제작사 공시가 CSV
- `claim_history(vehicle|shop)` → 합성 이력 DB
- `collision_prior(collision_type)` → 모사 데이터 기반 충돌부위 분포

### 6.3 기타 외부 자료
- 손해보험협회 과실비율 인정기준(과실비율정보포털): 도표별 기본과실 + 수정요소 + 관련 판례. RAG 대상. 확보 필요.
- 부품 가격: 국토교통부 규정상 제작사는 부품 소비자가를 자사 홈페이지에 공개하고 분기별 갱신. 인기 차종 3개 × 주요 외판 부품 20개 정도를 **수작업으로** CSV화(출처·조회일 기록). 대량 스크래핑 금지(약관 문제).

### 6.4 데이터 함정
1. **교통사고 영상과 파손 사진은 서로 다른 사고.** 영상 라벨 `damage_location` + 차종 크기로 같은 부위가 파손된 이미지를 짝지어 "합성 사고 건"을 만든다. 모순 사례는 일부러 다른 부위 사진을 짝지어 생성(정답 라벨 자동 생성).
2. AI Hub는 내국인만 신청 가능, 재배포 제한 가능. 저장소에는 파일 키 목록 + 다운로드 스크립트 + 재생성 스크립트만. 심사위원 재현 방식은 주최측에 미리 확인.
3. AI Hub API 다운로드는 분할 압축(`*.zip.part*`). 병합: `find "폴더경로" -name "파일명.zip.part*" -print0 | sort -zt'.' -k2V | xargs -0 cat > "파일명.zip"` (리눅스/WSL 권장).

## 8. 평가 지표

| 지표 | 방법 |
|---|---|
| 과실비율 정확도 | 완전 일치율, ±10%p 이내 비율 |

| 과잉 견적 탐지 | 심은 과잉 항목 precision / recall |
| 모순 건 탐지 | 모순 사례의 SIU 라우팅 비율 |

## 9. 3분 데모 시나리오
1. 정상 건(신호 교차로): 30초 안에 과실비율 + 근거 도표 + 인정 수리비 사정서 초안.
2. 과잉 견적 건: 사진은 앞범퍼 스크래치뿐인데 견적에 전조등 교환 → 조정 요청서.
3. 모순 건: 영상상 후방 추돌인데 전면 파손 청구 → SIU 이관 메모.

5. 평가 대시보드: 정확도, 차단액, 건당 토큰.
