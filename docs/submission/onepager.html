협의 근거 에이전트 Claim Evidence Agent

자동차보험 대물보상 담당자가 상대 보험사(과실)·정비공장(수리비)과 협의할 근거 묶음을 만드는 NVIDIA 스택 기반 에이전트
GitHub: https://github.com/googlershh/nvidia-car-claim-evidence-agent

문제

대물보상 담당자가 상대가 받아들일 협의 근거를 만들기 어려워, 결론이 예측되는 사고도 분쟁심의로 두 달 가까이 늦어집니다.

담당자는 사고 한 건마다 상대 보험사와 과실비율, 정비공장과 수리비를 합의해야 합니다. 합의가 안 되면 분쟁심의로 가는데, 2024년 약 15.7만 건이고 소심의만 평균 61일이 걸립니다. 심의 결정의 95%가 그대로 받아들여질 만큼 결론은 인정기준으로 예측되지만, 적용 도표·영상 속 시각·진술과의 차이 같은 근거를 일일이 만들기 어려워 협의가 길어집니다.

해결

  • 블랙박스 영상을 보고 사고유형을 판정해 과실비율 인정기준(제10차) 도표와 현행 기본과실을 인용
  • 피보험자 진술·상대 보험사 주장을 영상과 대조해 다른 점과 확인할 수정요소를 표시
  • 사진↔견적 대조로 사진에 없는 부위 청구를 찾아 조정 요청, 충돌부위 모순은 SIU 이관
  • 상대 보험사용 협의 근거 문서와 분쟁심의 가능성, 모든 결과는 담당자 승인 후 발송

NVIDIA 스택 구성

사용자 흐름

  • 담당자가 목표를 줍니다: "이 건 상대사와 공장에 보낼 근거를 만들어줘"
  • 에이전트가 영상·사진·견적·진술을 조사하고, 근거가 모자라면 영상 구간을 다시 묻습니다
  • 협의 근거 문서, 조정 요청서, SIU 메모 초안을 만들고 분쟁심의 가능성을 표시합니다
  • 담당자가 검토·승인한 뒤에만 외부로 발송됩니다

데이터와 검증

  • AI Hub 사고 영상 150건을 사람이 전수 검수해 라벨이 맞는 92건만 평가에 사용(라벨 오류·역할반전 발견)
  • AI Hub 사고유형 84개 → 인정기준 제10차 도표 65개 매핑, 기본과실 79/84 재현, 나머지는 개정 반영
  • 수리비 정답은 쏘카 견적의 실제 손해사정 전·후 금액
  • 모든 데이터 생성은 고정 시드, 스크립트로 재현 (원본 데이터는 저장소에 포함하지 않음)

구현 현황

완료
  • 검수된 평가 세트 92건, 합성 사고 건(영상+사진+견적+진술)과 정답
  • 인정기준 도표 매핑, 진술 대조, 협의 근거 문서·분쟁심의 가능성, 손해액 검증·SIU 라우팅
  • Brev A6000에 VSS(Cosmos3)와 NemoClaw 배포, 사고 영상 질의응답 동작 확인
  • 도구를 NemoClaw 스킬로 설치: 에이전트가 목표 한 줄로 조사 순서를 정하고, 수정요소마다 VSS에 영상 구간을 다시 물어 협의 문서에 반영 (C006: 약 6분, 도구 호출 약 20회)
진행 중
  • 영상 모델의 사고유형·역할 판정 정확도 측정(현재 소표본). C006은 역할 판단이 확신도 낮은 검수 라벨과 달라 재확인 중
  • 담당자용 데모 화면: 사고 건 선택 → 에이전트 단계·도구 호출 → 협의 문서 → 승인
통계 출처: 보험연구원 「자동차보험 민원·소송 현황과 제도개선 방향」(2026) 인용 보도, 과실비율분쟁심의위원회. 무료 모델 API가 과부하(503)로 자주 막혀 OpenRouter 유료 경로를 씁니다. 과실 판정은 "초안 + 근거 + 사람 승인"을 원칙으로 합니다.
